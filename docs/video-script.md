# 演示视频脚本（60 秒 + 3 分钟）

面向 GitHub 作品集与面试自荐。60 秒版放 README / 简历二维码，3 分钟版放 B 站或面试时投屏。

---

## 一、录制前准备

**环境**

- 起服务：后端 `127.0.0.1:8000`、前端 `127.0.0.1:3000`
- 浏览器窗口 1440×900 或 1920×1080，缩放 100%，F11 全屏，隐藏书签栏
- 刷新页面清空历史；语言先设为中文（最后一段再切外语）
- 关闭输入法候选框、微信/QQ 弹窗、系统通知

**录屏**

- Windows：`Win + G`（Xbox Game Bar）或 OBS；建议 OBS，1080p / 30fps / MP4
- 录制区域只框浏览器内容区，不要带任务栏
- 鼠标移动放慢，停在卡片旁边而不是压在文字上

**提问文本（直接粘贴，避免输入错误）**

```text
上海天气怎么样
我想去外滩、豫园、东方明珠，帮我规划游玩路线
上海迪士尼门票多少钱
从杭州到上海怎么去，高铁还是飞机
1+1等于几
```

> 说明：模型单次响应约 4~8 秒，飞猪类查询约 6~9 秒。录制时保留 1 秒"思考中"动画更有真实感，超过 3 秒的等待在后期剪掉。

## 三、3 分钟版结构

| 段落 | 时长 | 内容 |
|---|---|---|
| 1. 问题与定位 | 0:00-0:25 | 外国游客的信息割裂：天气/地图/门票/酒店分散；模型会聊但给不出可预订结果 |
| 2. 功能演示 | 0:25-1:30 | 天气 → 路线 → 门票 → 酒店 → 交通，每条一句卖点 |
| 3. 多语言与范围约束 | 1:30-1:50 | 切英文/日文界面；问「1+1」展示固定话术 |
| 4. 架构讲解 | 1:50-2:30 | 架构图：Nginx → Node 网关 → FastAPI → 工具；讲四层时间预算与 artifact 设计 |
| 5. 工程取舍 | 2:30-2:50 | 隧道 keep-alive、飞猪 CLI 超时误杀、缓存击穿、移动端安全区各一句 |
| 6. 数据与收尾 | 2:50-3:00 | 500 并发全 200、缓存命中 10ms；仓库地址 |

## 四、60 秒版中文旁白

> 语速约 4 字/秒，读完即切画面。

**0:00-0:05**
这是 Trip Planner，一个面向来华外国游客的 AI 旅行助手。

**0:05-0:14**
它不是一个只会聊天的机器人。问天气，拿到的是高德的真实数据，而不是模型编的内容。

**0:14-0:26**
说一句想去哪，它会调用高德路径规划：地图、总里程、驾车耗时、游览顺序，一次给全。

**0:26-0:35**
门票和游玩项目来自飞猪实时检索，价格以下单页为准，点卡片就能预订。

**0:35-0:45**
跨城市出行，高铁、飞机、大巴、自驾四种方案并排比较，价格来源标注得清清楚楚。

**0:45-0:52**
界面和回复支持六种语言。同时它被限制在旅行范围内——问算术题，只会礼貌地给你功能清单。

**0:52-1:00**
模型负责决策，代码负责事实。五百并发压测全部成功，超时自动降级。代码和设计文档都在 GitHub。
